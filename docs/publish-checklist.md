# 微信小程序发布清单

当前状态：小程序代码、交互、图表和免责声明页已完成；还差**正式主体信息、服务器域名、类目资质和上传密钥**，这些只能由账号持有人提供。

## 一、需要你提供或确认

### 1. 小程序账号

- 正式小程序 **AppID**（不能再用开发者工具里的测试号 `wxca7a742cf576fb96`）。
- 微信公众平台管理员扫码登录权限。
- 主体类型：个人 / 企业 / 个体工商户。
- 小程序名称是否可用：建议在公众平台先查“**息壤股票分红计算器**”是否被占用；名称确定后，代码里的展示名统一使用它。
- 若选择“金融业 → 股票信息服务平台”类目，需按微信要求提供企业主体及相应资质；个人主体不能选择金融业类目。

### 2. 后端与域名

小程序不能请求 `127.0.0.1`，正式版必须使用 HTTPS 域名：

- 一台可运行 Node 20 的服务器（阿里云/腾讯云/轻量服务器均可），或微信云托管。
- 一个已备案域名，例如 `api.example.com`。
- 该域名的 **ICP 备案**（中国大陆服务器必须）。
- 有效 HTTPS 证书（TLS 1.2+）。
- 在微信公众平台 → 开发管理 → 开发设置 → 服务器域名，把 `https://api.example.com` 加入 **request 合法域名**。
- 服务器安全组开放 443（不要直接暴露 3210）。

当前已提供 [Dockerfile](../Dockerfile) 和 [Nginx 示例](../deploy/nginx.conf.example)，可直接部署。

### 3. 类目与资质

最可能的选择：

- **工具 → 信息查询（或后台实际提供的计算器类目）**：适合“历史分红再投资测算”工具，个人主体也可能可选；但审核若认定涉及股票信息服务，会要求金融类目。
- **金融业 → 股票信息服务平台**：适合提供股票行情/信息服务的非个人主体，通常需要企业资质及 ICP 等材料，具体以公众平台类目页为准。

建议先按“工具”提交，页面文案保持“历史数据测算、不构成投资建议”，不要出现荐股、收益承诺、买卖信号。若审核要求金融类目，再按主体资质调整。

### 4. 隐私与合规

- 在公众平台填写《小程序隐私保护指引》。
- 本项目当前不登录、不读取头像/手机号/位置/通讯录；只把股票代码、日期、金额发送到计算服务。
- 需要确认一个**数据纠错/用户反馈渠道**（可用小程序自带“反馈与投诉”，也可提供邮箱）。
- 股票数据来自东方财富/Yahoo Finance，正式商用前需确认数据使用条款；若不能商用，需换成有授权的数据源。
- 完成**小程序备案**（公众平台 → 设置 → 基本设置 → 小程序备案）。

### 5. 上传密钥

在公众平台 → 开发管理 → 开发设置 → 小程序代码上传，生成并下载代码上传密钥：

- 文件通常命名为 `private.<appid>.key`。
- 把服务器出口 IP 加入上传密钥的 IP 白名单；或在开发者工具里手动上传。
- 密钥只放在本机/CI 密钥变量中，**不要提交到 Git**。

### 6. 搜索发现设置

代码里的页面标题已经改为“息壤 · 股票分红计算器”，但**微信搜索主要看公众平台里的名称、简称和简介**，需要在公众平台设置：

- 名称/简称：优先使用「息壤股票分红计算器」；若被占用，保留「息壤」+「股票分红计算器」两个核心词。
- 简介：写清“股票分红再投资计算器，支持 A 股/港股/美股历史回测、定投、分红复利和年化收益”。
- 服务类目：按实际功能选择；不要为了搜索把类目选成不匹配的金融类目。
- 页面标题、分享标题和正文关键词已统一为“股票分红计算器”。
- `sitemap.json` 已允许微信索引全部页面。

名称、简介和类目都在公众平台审核，代码无法替代。

## 二、我可以继续代做

拿到上面的信息后，我可以：

1. 把 `miniprogram/config.js` 的 `apiBase` 改成正式 HTTPS 域名。
2. 构建并推送后端 Docker 镜像，配置 Nginx/HTTPS。
3. 用 `miniprogram-ci` 上传体验版/正式版。
4. 生成隐私说明、类目说明、审核备注和测试账号说明。
5. 根据审核驳回原因修改文案/页面并重新提交。

## 三、发布步骤

```powershell
# 1. 部署后端（示例）
docker build -t xirang-dividend .
docker run -d --name xirang-dividend --restart unless-stopped `
  -p 127.0.0.1:3210:3210 xirang-dividend

# 2. 配置 Nginx + HTTPS 后验证
curl https://api.example.com/api/health

# 3. 修改小程序 API 地址
# miniprogram/config.js -> apiBase: 'https://api.example.com'

# 4. 上传（需要 private key）
npm install -D miniprogram-ci
$env:WX_APPID = 'wx...'
$env:WX_PRIVATE_KEY_PATH = 'D:\keys\private.wx....key'
$env:WX_VERSION = '1.0.0'
npm run mp:upload

# 5. 公众平台提交审核 -> 审核通过 -> 发布
```
